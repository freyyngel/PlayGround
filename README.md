# PEE 50 — The Great American Relief Run

A cartoon road-trip game: one van, fifty state restrooms, and a bladder with a plan. Tap a state, let the van drive, and stamp the map before the pressure hits 100%.

- **Play:** open `index.html` (or run `./start.sh`).
- **Controls:** tap/click a state pin or use the state list. Hold **CLENCH** or `Space` to slow the urge (and the van).
- **Goal:** relieve yourself in all 50 states. Arrive with 55%+ pressure for a Perfect Relief bonus. Three accidents and the run ends.
- **Best score** is saved locally.

The map uses U.S. Census-derived state boundaries from [PublicaMundi MappingAPI](https://github.com/PublicaMundi/MappingAPI). Bebas Neue and Space Grotesk are licensed under the SIL Open Font License (see `assets/fonts/`).
